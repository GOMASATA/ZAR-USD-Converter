# 💱 ZAR ↔ USD Currency Converter

A simple Streamlit app that converts between South African Rand (ZAR) and US Dollar (USD) using live exchange rates from Alpha Vantage.

## 🚀 Features
- Real-time ZAR ↔ USD conversion
- Interactive Streamlit interface
- Powered by Alpha Vantage API

## 🛠 Installation
Clone the repository and install dependencies:

```bash
git clone https://github.com/GOMASATA/ZAR-USD-Converter.git
cd ZAR-USD-Converter
pip install -r requirements.txt
